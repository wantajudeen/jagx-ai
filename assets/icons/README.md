# App Icon

Place the JagX AI logo here as:

```
assets/icons/app_icon.png
```

## Requirements
- Square PNG
- Recommended size: **1024×1024**
- Transparent or solid black background
- The teal abstract mark we generated

## How to apply the icon

After placing `app_icon.png`:

```bash
flutter pub get
flutter pub run flutter_launcher_icons
```

This generates all Android and iOS launcher icon sizes automatically.

## Logo used
Abstract teal mark on black — JagX AI brand mark.
